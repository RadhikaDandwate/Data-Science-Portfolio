# Data Science Portfolio

Welcome to my Data Science Portfolio!

This repository contains my academic projects, practical implementations, and assignments related to Data Science, Statistics, Python Programming, Data Analysis, and SQL.

## Projects and Work

### 1. Engineering College Placement Analysis
Analysis of placement statistics, salary packages, and other placement-related information across five engineering colleges using Python, Pandas, NumPy, Matplotlib, and Regular Expressions.

### 2. Personal Household Expense Management & Analysis
A household expense management project involving SQL-based data management and analysis, supported by a project presentation.

### 3. Student Lifestyle, Learning Habits & Domain Skill Development Analytics
A real-life statistics project exploring student lifestyle patterns, learning habits, and domain skill development.

### 4. Business Understanding
Defining business objectives and constraints for given business problems.

### 5. Data Understanding
Understanding seven datasets through feature descriptions, data types, and feature relevance.

### 6. Exploratory Data Analysis (EDA)
Exploratory analysis of seven datasets using Python, Pandas, NumPy, Matplotlib, and Seaborn.

### 7. Data Preprocessing
Preprocessing seven datasets using missing-value handling, duplicate removal, outlier treatment, normalization, standardization, transformations, encoding, and feature selection.
